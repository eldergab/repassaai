# Repassa Aí – Escolas (AFFE)
Site estático e PWA do programa nas escolas. Suba o conteúdo desta pasta em `escolas/` no repositório.
1. O WhatsApp (`CFG.wa`) e o site da AFFE (`CFG.affe`) ficam no começo de `app.js`.
2. Os formulários abrem o WhatsApp com os dados preenchidos (nada é gravado em servidor).
3. Para instalar como app, abra no celular e escolha "Adicionar à tela inicial".
4. Este site não tem ligação com o projeto dos salões; a ligação entre os dois fica no site da AFFE.
5. Valores de visualizações e custos são estimativas; revise após a 1ª rodada.
