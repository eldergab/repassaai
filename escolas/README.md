# Repassa Aí (AFFE)
Site estático e PWA. Funciona direto no GitHub Pages (Settings > Pages > branch main, pasta raiz).
1. O WhatsApp (`CFG.wa`) e o site da AFFE (`CFG.affe`) ficam no começo de `app.js`.
2. Os formulários abrem o WhatsApp com os dados preenchidos (nada é gravado em servidor).
3. Para instalar como app no celular, adicione também `icon-192.png` e `icon-512.png` ao manifest.
4. Valores de visualizações e custos são estimativas; revise após a 1ª rodada.
